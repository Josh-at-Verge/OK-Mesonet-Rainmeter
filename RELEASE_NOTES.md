Five Oklahoma Mesonet widgets for Rainmeter: full local weather, local weather without the temperature graph, small with forecast, small conditions, and fire weather.

- Dark frames and switchable dark/original iframe colors.
- Configurable station ID, size, and refresh interval.
- Includes both architectures of the NSTechBytes WebView2 Rainmeter plugin v1.0.0 with its MIT license.

Install Rainmeter 4.5+ and Microsoft WebView2 Evergreen Runtime on Windows 10/11, then download and double-click MesonetDark-1.0.0.rmskin.

The default station is Norman (NRMN). Dark mode alters chart/image colors; use Original for source colors. The request time is not proof of fresh observations.

Validation: local browser wrapper and archive checks passed. Windows/Rainmeter execution and live Mesonet iframe rendering remain unverified.
